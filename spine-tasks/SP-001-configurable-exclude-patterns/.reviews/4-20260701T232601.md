### Blocking issues

1. **`cli/internal/scope/scope.go:27-66`** — When exclusions are lifted, `Partition` computes `reviewed` with the **current** (lifted) `diff.Options`, so hunks that were previously filtered out appear in `baseline..lastReviewedAt` and match as already **Approved** instead of **ToReview**. Reproduced manually: `Partition(base, HEAD, "", exclude *.txt)` → 0 toReview; then `Partition(base, HEAD, HEAD, no exclude)` → `f2.txt` in **Approved**, not ToReview. This breaks PROMPT completion criterion “`stet run` after lifting exclusions reviews previously skipped doc hunks” and `docs/review-process-internals.md` §6.3 incremental bullet.

2. **Missing test:** `cli/internal/scope/scope_test.go` (or `cli/internal/run/run_test.go`) — no regression test for exclude lift. Add a case mirroring the repro above (exclude all hunks in a diff, advance `lastReviewedAt` to HEAD, lift exclusions, assert skipped paths land in `ToReview`).
